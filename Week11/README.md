## Neural Networks Content
### Basic Concepts
- Traditional ML vs Deep Learning
  - Traditional ML: Requires manual feature engineering
  - Deep Learning: Automatic feature extraction through layers

### Network Architecture
- Components:
  - Input layer
  - Hidden layers
  - Output layer
- Fully connected networks (MLPs)
  - Each neuron connected to all neurons in adjacent layers
- Parameters:
  - Weights
  - Biases
  - Activation functions

### Activation Functions
- Types:
  - Sigmoid (0 to 1)
  - Tanh (-1 to 1)
  - ReLU (0 for negative, linear for positive)
  - Leaky ReLU
  - Linear
- Purpose:
  - Enable non-linear learning
  - Prevent vanishing gradient problem

### Training Process
- Forward pass: Input → Output
- Back propagation: Adjusting weights based on errors
- Cost function optimization
- Learning rate importance for convergence

### Practical Example
- Simple neural network fitting by hand demonstrated in Excel
- Shows iterative weight adjustment process
- Importance of learning rate in convergence
