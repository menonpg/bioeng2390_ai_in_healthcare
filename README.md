## 👋 Welcome to AI in Healthcare!

Welcome to BIOENG 2390: AI in Healthcare for Spring 2026! I'm excited to guide you through this journey of applying artificial intelligence and machine learning to solve real-world healthcare challenges.

## 📚 Course Overview

This course provides a comprehensive, hands-on introduction to artificial intelligence and machine learning in healthcare applications. We'll start from the fundamentals of programming and build our way up to developing sophisticated AI models for healthcare data analysis.

### What You'll Learn:

- **Programming Fundamentals**: Master Python, R, and MATLAB for data science and AI
- **Development Environments**: Set up and use modern tools like Jupyter, VS Code, Google Colab, and more
- **Data Science Basics**: Work with time series, image, and text data from healthcare domains
- **Machine Learning Models**: Build linear, nonlinear, and deep learning models
- **Real-World Applications**: Apply AI to solve actual healthcare problems
- **Best Practices**: Learn version control with Git/GitHub and collaborative development

### Course Philosophy

In this course, we believe in **learning by doing**. Each week, you'll work with real healthcare datasets, write code, build models, and see immediate results. My goal is not just to teach you theory, but to make you confident practitioners who can apply AI to improve patient outcomes.
